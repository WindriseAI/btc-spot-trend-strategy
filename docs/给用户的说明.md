## 一、这个程序做什么、不做什么

这个程序每天看一次比特币（BTC-USDT）日线收盘价，按固定规则算出「现在应该拿几成比特币」，然后在你自己的欧易（OKX）**现货**账户里调到目标比例。

程序自带的安全边界：
- **只做 BTC-USDT 现货、只做多、无杠杆**（`cash` 模式 + `IOC` 限价单）。
- 代码里**没有**提现、划转、借币、合约、永续、期权的任何接口。
- **每天最多下一笔单**，重复运行或中途崩溃都不会重复下单。
- 发现 API key 带有「提现」权限，或账户里存在合约/杠杆持仓或借币时，程序会直接拒绝下单。

详细回测和规则说明见 [README.md](../README.md) 和 [docs/backtest-report.md](backtest-report.md)。

## 二、安装（约 5 分钟）

电脑上需要 **Python 3.10 或更新版本**。进入项目目录后打开终端，安装依赖：

```bash
pip install -r requirements.txt
```

先不填任何密钥，试跑一次只读日报，确认环境和网络正常：

```bash
python -m btc report
```

这一步不会连账户、不会下单，只打印今天的信号。

## 三、先用模拟盘（Demo 模式）试跑

**强烈建议先在欧易模拟盘连续跑 2～4 周**，确认信号、日报和下单都符合预期，再考虑实盘。

### 1. 创建欧易模拟盘 API key

1. 登录欧易网页版 → 顶部「交易」→「模拟交易」（Demo Trading）。
2. 在模拟交易界面，点右上角头像 →「模拟交易 API」→「创建模拟盘 API key」。
3. 权限**只勾选「读取」和「交易」**，**不要勾选「提现」**。
4. 记下生成的 `API Key`、`Secret Key`（只显示一次）和你自己设置的 `Passphrase`（口令）。

### 2. 配置 `.env` 文件

把项目根目录的 `.env.example` 复制一份，改名为 `.env`（该文件已被 `.gitignore` 忽略，**只保存在你自己的电脑上，绝对不要发给任何人，包括作者**）：

```dotenv
OKX_DEMO_API_KEY=你的模拟盘 API key
OKX_DEMO_API_SECRET=你的模拟盘 Secret
OKX_DEMO_API_PASSPHRASE=你的模拟盘口令

# 可选：填写作者提供的欧易 AI Builder Code（1~16 位字母或数字；不增加你的手续费）
OKX_AI_BUILDER_CODE=
```

如果你的网络访问 `www.okx.com` 需要代理，可以在 `.env` 中取消注释并设置 `OKX_PROXY=http://127.0.0.1:7890`。

### 3. 运行模拟盘

```bash
python -m btc paper
```

程序会在你的欧易模拟盘账户里按规则模拟下单，并打印中文日报。

## 四、准备上实盘

确认模拟盘运行稳定后，如决定使用实盘：

### 1. 在欧易创建实盘 API key（安全建议）

1. **建议使用欧易子账户**：专门建一个只跑本策略的子账户，把打算交给策略管理的资金转入该子账户的**交易账户**（与你其他资产和合约完全隔离）。
2. 在欧易网页版（**实盘界面**，不是模拟交易）→ 右上角头像 →「API」→「创建 API key」。
3. 权限**只开「读取」和「交易」**，**绝对不要开「提现」**（程序一旦检测到提现权限会直接拒绝运行）。
4. **绑定运行机器的公网 IP**：既更安全，也能避免未绑 IP 的 key 连续 14 天不用被欧易自动作废。
5. 妥善保管 `API Key`、`Secret Key`、`Passphrase`，只写入你本机的 `.env` 文件。

### 2. 配置实盘并开启总开关

在 `.env` 中填入实盘密钥，并将 `LIVE_CONFIRM` 设为 `yes`（没有这一行，`live` 模式会拒绝运行）：

```dotenv
OKX_API_KEY=你的实盘 API key
OKX_API_SECRET=你的实盘 Secret
OKX_API_PASSPHRASE=你的实盘口令
LIVE_CONFIRM=yes

# 可选：作者的 AI Builder Code（与模拟盘相同，不增加你的手续费）
OKX_AI_BUILDER_CODE=
```

同时确认：
- 资金已从「资金账户」划转到「交易账户」。
- 该交易账户里没有未平仓的合约/杠杆持仓或借币（否则程序会拒绝下单）。
- 如你的欧易现货吃单手续费率不是默认的 0.1%，可在 `.env` 中设置 `SPOT_FEE=0.002`（按实际费率填写）。

### 3. 运行实盘

```bash
python -m btc live
```

## 五、日常使用与停止方式

| 命令 | 作用 | 是否下单 |
|---|---|---|
| `python -m btc report` | 查看今天信号和建议操作 | 不会 |
| `python -m btc paper` | 模拟盘运行并在模拟盘下单 | 模拟资金 |
| `python -m btc live` | 实盘运行并下单（需 `LIVE_CONFIRM=yes`） | **真实资金** |
| `python -m btc weekly` | 查看最近 7 天信号与净值对比周报 | 不会 |
| `python -m btc confirm-resume live` | 熔断暂停期结束后手动确认恢复满仓 | 不会 |

- **建议运行时间**：每天北京时间 **08:22**（UTC 00:22，日线收盘后）。
- **`state/` 目录请务必保留**：里面记录了历史最高净值、存取款和熔断状态，不要随意删除。
- **想暂停下单**：把 `.env` 里的 `LIVE_CONFIRM=yes` 改成 `LIVE_CONFIRM=no`，或停掉定时任务。
- **彻底切断**：直接在欧易网页版删除该 API key 即可。
